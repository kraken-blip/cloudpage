# CloudPage — передача №1

18.11.2026. Полный контекст и карта исходников находятся в [HANDOFF.md](HANDOFF.md). Перед доработкой прочитайте оба файла и сверьте текущие исходники.

## Последние завершённые работы

1. Собран личный кабинет CloudPage с карточками серверов. Адрес открывается из карточки, авторизация выполняется в самой целевой панели.
2. Подготовлен самораспаковывающийся установщик и терминальное меню. Добавлены выбор порта, управление учётными данными, возврат из управления в главное меню и команда для повторного вызова установщика.
3. Добавлены адаптивный выбор страны, логотип и значки для браузера и экрана «Домой».
4. Разделена установка CloudPage и Docker. Для имеющегося Docker добавлена установка недостающих CLI-плагинов по безопасному плану APT.
5. Добавлены предварительные проверки и пункт 5 для повторного запуска после обрыва. Проверены отдельные сценарии с имитацией Docker и APT. Обновлён короткий гайд.
6. Репозиторий, установщик, гайд и дизайн собраны в одной папке `Cloud Page`. Установщик пересобран из нового расположения, содержимое и синтаксис проверены.

7. Папка исходников теперь называется `cloudpage/`. Спецификация и HTML-макет в `design/` тоже переименованы под CloudPage. После переименования исходников установщик успешно пересобран.

## Открытые пункты
